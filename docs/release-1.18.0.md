# Mission: Sangreal 1.18.0 — Hausmann Combat Form

Adds **Kurt Hausmann — Newly Made Vampire**, a separate combat actor for five armed investigators, with a newly generated identity-matched portrait and matching prototype token.

- STR 7, AGI 5, WIT 3, EMP 1; Brawl 4; Armor 2; Fear 2/3. Embedded claw and bite weapons plus six named ability items provide the complete combat reference.
- Blood Frenzy, ballistic resistance, wall movement, UV/sunlight vulnerability and a restricted second initiative activation make him a dangerous solo opponent. Grapples, damage, light and escape remain actionable counterplay.
- The DA walkthrough links directly to the new combat actor and uses its revised stats. The earlier Hausmann actor and all clue evidence remain available.
- The NPC rules require manual adjudication: track scalar STR, conditional damage, and the extra initiative slot on the sheet/tracker. This release installs content, not combat automation.

Update the module and run **Mission: Sangreal → Content Installer**. Use the actor named **Kurt Hausmann — Newly Made Vampire** for the ward battle. See `docs/hausmann-vampire-combat.md` for the full reference.
