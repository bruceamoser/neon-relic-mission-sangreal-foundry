# Investigator photographs — GM handoff

24 optional snapshots: 16 mundane subjects and 8 visible observations. No hidden symbols, text puzzles, background watchers, or extra evidence are intended. Use alongside the existing detailed clue images.

Share a card only when players photograph the subject with appropriate access and matching conditions. The images are illustrative viewpoints, not authoritative architectural plans or proof of capture time. NPC pictures show appearance only. The empty hangar is for after the aircraft departs. GM classifications and inference limits are not player text.

Restart Foundry after deploying the rebuilt module so the new pack is registered, then use the existing Content Installer. Cards appear under Investigator Photos. No world documents have been imported automatically.

All files are native-size WebP at q85, totaling 3.89 MB. PNG masters and generation prompts remain outside the module build. Built-in ImageGen produced the images. User QA is pending.
